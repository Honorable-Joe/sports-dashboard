Athlete-IQ V12
By: Coach Ahmed Youssef

This update keeps the V11 engine/UI and adds:
- Expanded screening-to-corrective mapping for posture and directional mobility findings.
- Left/right asymmetry-aware corrective selection.
- Session-specific corrective selection that preserves primary and secondary training goals.
- Directional mobility flags using low-range and side-to-side signals.
- Exercise-level Session Follow-Up with actual load, reps, exercise RPE, technique and performance.
- Session RPE, pain, duration and coach notes.
- Adaptive load progression/regression on the next exposure of the same exercise.
- Same-week re-exposure support for key compound/anchor lifts so Day 1 performance can influence Day 4.
- Deadlift 1RM field for a better initial loading reference.
- Reorganized navigation with a simple logical sequence and Equipment + Club Load grouped together.
- Existing V11 protections retained: sport/position locks, hard equipment filtering, month-to-month variation, concrete warm-ups, multiple MetCon protocols, automatic regeneration, and no Generate Plan button.
